# 待办手写体后续路线

本页仅描述 Couple OA Todo；另一款便签手记的 8105 字公开版见 [Note 说明](https://github.com/georgehuang000/couple-oa-todo-font/blob/main/note/README.md)。

待办手写体 v0.1.0 发布 604 汉字设计母版。待办风格的 8105 字扩展仍是后续目标，尚未发布。

1. **保留设计基准**：固定本版的核心轮廓和间距，继续以「待办事项」的字形为参考；扩字不能覆盖已认可的字形。
2. **更换结构素材**：选择覆盖目标字符且允许衍生字体的开放字体，核对具体版本、许可证及保留名称要求。记录所有文件摘要与获取地址。
3. **核对模型链路**：分别核对代码、权重、训练数据和输出使用条件。任何一项缺少依据时，在实验记录中明确，不把源码仓库的主许可证当作整条链路的授权。
4. **先做对照样本**：覆盖偏旁、左右 / 上下结构、密集笔画、数字与标点。检查原版风格保留程度后，再批量扩展。
5. **完整验收**：检查 8105 主表、非 BMP 字符、结构、错字、度量、转换保真度、缺字回退和真实排版。覆盖检查与视觉检查分开记录。
6. **发布新的明确版本**：更新字符清单、来源记录、许可证、字体内元数据和可复现构建；在 release 中说明新旧字形的差异。

此列表是后续工作范围，不表示扩字替换已经完成，也不提供未经测试的完成日期。

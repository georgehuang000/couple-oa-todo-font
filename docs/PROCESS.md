# 制作与开源记录

## 设计母版

以最初「待办事项」的手写风格为锚点，保留 8 个原设计字形，先生成 16 个新字，形成 24 字试验。随后按项目标题、界面和常用短句扩展出 604 汉字的设计母版，同时补齐字母、数字和符号。

制作过程采用「字图 → 结构核对 → 完整笔画分割 → Potrace 追踪 → 字体轮廓 → 真实排版检查」。逐张生成并检查了 41 张首轮母版及 2 张修正母版。问题包括小点遗漏、相似部件混淆、笔画越过切字网格、不同批次的字面大小波动。通过定向修正、连通笔画归属和统一光学尺寸校准解决；保留汉字自然比例，没有把每个字强行拉成相同方框。

风格评审中，项目所有者更喜欢原始组图的字形，因此本版保持这些轮廓与字距，不应用后来的几何化风格调整。

## 2026-10-16 开源整理

1. 核对生成链路，区分设计母版和少样本模型扩字，确认原图可公开。
2. 根据所有者选择，发布 604 汉字母版；完整 8105 字实验暂不进入开放授权发布。
3. 提取原版 731 个字符，追加 12 个自主绘制的括号，共 743 个字符；逐字比较所有点、轮廓结束索引、点标志和水平度量，均与既有设计一致。
4. 使用 fontTools 官方 TTX 格式导出可编辑母版，分成字形与字体表。新增一个仅依赖 fontTools 的离线构建入口，不要求复现历史模型流程。
5. 写入字体家族、版本、项目地址和 OFL 许可元数据。使用独立的公开字体仓库，不带入应用源码、项目私有文案、模型权重或机器路径。
6. 提供字符清单、TTF / WOFF、单字 SVG、试字页、安装包与来源记录。

发布核验记录保存在 `verification/`。历史设计检查不替代专业人工字库审校；复杂字在小字号下仍需按实际场景判断。

## 可复用的判断

“覆盖了多少字”“字形是否正确”“是否符合目标风格”“可以如何对外授权”是四个独立的发布条件。产品层面先明确目标场景和字符边界；工程层面用可定位、可比较、可重建的字形母版支撑后续修正。不要为追求更大的字数，把来源不同的实验结果直接并入正式开源版。

# 来源与许可范围

记录日期：2026-10-16。发布范围：v0.1.0 的 604 个汉字及 139 个其他字符。

| 部分 | 来源 | 本次发布处理 |
| --- | --- | --- |
| 待、办、事、项、处、理、申、请 | 项目最初的设计参考图 | 项目所有者确认来自本人设计或 AI 生成，允许公开；保留现有字形 |
| 其余 596 个汉字 | image_gen 生成字图、逐格核对及局部修正 | 从已审阅的设计母版保留，不使用少样本扩字结果 |
| 62 个拉丁字母与数字、! / ? | image_gen 生成字图 | 经图像分割、校对和轮廓追踪 |
| 72 个其他标点与符号 | 项目绘制的矢量笔画及全角变体 | 保留原生路径 |
| 3 个空格 | 原生排版度量 | 普通空格、不换行空格、全角空格 |

来源类型逐字列在 `data/characters.json`。原设计中的“活、喜、末、藏、望、截”曾通过系统字体结构辅助图检查笔画，再由图像模型修正；没有提取辅助字体轮廓，也没有把它们直接转码装入本版。AI 辅助设计和后期轮廓工程均有参与，不能把所有字形描述为人工逐字书写。

## 授权

项目所有者要求开源，并在 2026-10-16 确认原设计图可以公开；随后选择先发布 604 字设计母版，将完整扩字版本留待替换素材来源后处理。

本次实际发布的字体文件与字形源码采用 OFL-1.1，项目独立编写的通用构建与预览工具采用 MIT。模型服务输出的版权保护资格可能因地区不同，本许可只授予项目作者能够授予的权利，不宣称获得第三方软件或字体的权利。

## 生产工具

- [fontTools](https://github.com/fonttools/fonttools)：MIT 许可。用于字体表、TTX、TTF、WOFF 的转换；代码作为外部依赖，不随仓库复制。
- [Potrace 1.16](https://potrace.sourceforge.net/)：此前用于图像追踪；不分发其程序或源代码。本版直接从冻结的 TTX 轮廓构建，无需 Potrace。
- image_gen：前期图像生成工具；本仓库发布已经完成的字形设计，不包含模型权重，也不要求下载者调用服务。

## 未纳入本次发布的实验

8105 字实验包含 7501 个 MX-Font 扩字结果，其结构条件曾使用 Windows SimSun / SimSun-ExtB。微软的[字体使用说明](https://learn.microsoft.com/en-us/typography/fonts/font-faq)限制系统字体的转换和逐字位图字库制作；我们没有将“输出不是原轮廓”作为可无条件授权的依据。这是当前的发布范围决定，不是对 AI 输出法律地位的最终结论。

[MX-Font](https://github.com/clovaai/mxfont) 的主项目采用 MIT，其 `models/modules/modules.py` 引用 FUNIT，[NOTICE](https://github.com/clovaai/mxfont/blob/main/NOTICE) 包含 CC BY-NC-SA 条款。组件代码的许可不应直接等同于生成图像的许可。本仓库不包含这些模型代码、权重、逐字内容输入、生成的扩字轮廓或二进制字体。

未来扩字需单独记录内容源字体、风格参考、模型、权重和训练数据的已知许可。OFL 字体用于生成新字体时，也应遵循 [OFL FAQ 1.25](https://openfontlicense.org/ofl-faq/) 的衍生字体许可要求。

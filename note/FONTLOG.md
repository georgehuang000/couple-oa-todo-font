# Fontlog

## 2.100 — 2026-10-16 — 首个公开版本

- 在两人手写字体项目中发布便签手记，与待办手写体分别维护，字体与母版采用 SIL OFL 1.1；独立构建工具采用 MIT。
- 覆盖 8105 个规范汉字与 129 个其他字符，共 8234 个字符，含 196 个非 BMP 字符。
- 保留原有 735 字的轮廓和字距，包含小写 e、“常”“美”“可”的修复。
- 用 OFL 的思源宋体 SC 2.003 替换历史内部版本的 Windows 字体内容输入，重新生成全部 7499 个扩展字。风格参考仍是本项目 64 个原便签字。
- 保留直接绘制的三笔“士”修正母版。轮廓处理只排除已定位的固定角落背景点，不使用通用的小点删除规则。
- 提供分字 TTX 可编辑源、从源重建脚本、覆盖／原字／轮廓／许可检查、离线试字页和完整字表。
- 生成方法、实际检查范围、模型来源和已知限制见 `PROVENANCE.md` 与 `qa/`，不沿用内部版本的完整视觉验收声明。
